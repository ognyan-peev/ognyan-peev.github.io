# Публикуване на новата версия

1. Разархивирайте ZIP файла.
2. В GitHub отворете хранилището `ognyan-peev.github.io`.
3. Изберете **Add file → Upload files**.
4. Качете цялото съдържание на разархивираната папка, включително папката `assets`.
5. Потвърдете с **Commit changes**.
6. Изчакайте няколко минути и отворете сайта с **Ctrl + F5**.

Версията добавя романа „БЯГАЙ, ПРИЯТЕЛЮ, БЯГАЙ“, подрежда романите по поредици и добавя обща страница „Коментари“ с Disqus. Google Analytics, изборът за статистически бисквитки и запазването на мястото за четене са запазени.
