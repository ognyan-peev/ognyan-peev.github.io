# Защита срещу автоматизирано изтегляне

## Какво е приложено на публичния сайт
- robots.txt ограничава достъпа на доброволно спазващите правилата търсачки до машинно четимите файлове с книги.
- Това НЕ блокира злонамерени ботове; файловете са публични и остават директно достъпни.

## Подготвена реална защита (все още НЕ е активирана)
Папката cloudflare-worker съдържа работен шаблон за Cloudflare Workers Rate Limiting:
- за заявки към /assets/data/*.js: приблизително 40 заявки на 60 секунди от един IP;
- HTTP 429 при надхвърляне; нормалното четене не изисква регистрация;
- останалите страници минават без лимит.
За настройване са нужни Cloudflare акаунт, собствен домейн, маршрутизация на домейна през Worker, и проверка на достъпа. Не променяйте DNS без резервен план.
